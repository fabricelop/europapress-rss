Mi historial

Sesiones GPS locales y recorridos importados. Toca un día para centrar el mapa en una posición registrada.

Importar GPS

Admite GPX con trackpoints y etiquetas <time>. No accede a fotografías. Si faltan fechas, no asigna segundos inventados.

Ajustes y privacidad

Importante: esta es una prueba web para iPhone. El GPS funciona mientras Safari mantiene activa la página; iOS puede suspenderlo al bloquear la pantalla. Para registrar 24 horas y crear widgets necesitamos la versión nativa.
Todo se guarda en este navegador. No se envían tus posiciones a ningún servidor.
