Diagnóstico de acceso IPv4 / IPv6

Prueba hecha desde este iPhone y esta conexión. No cambia el router ni instala nada. Compara el acceso a un sitio solo IPv4, otro solo IPv6 y los Workers de TTActualidad y FabCalendar.

Volver a TTActualidad

Una prueba satisfactoria de IPv4 solo demuestra conectividad general mediante IPv4 o traducción NAT64; no fuerza a TTActualidad a usar IPv4. La prueba de Workers comprueba disponibilidad desde Safari, pero no puede saber qué familia IP eligió Safari. Los resultados son locales: no se envían a ningún servidor de diagnóstico.
