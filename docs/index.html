Acerca de los datos y la conexión

Esta web se sirve desde GitHub Pages. Consulta solo archivos editoriales públicos de GitHub, con una copia estática de respaldo. No utiliza Cloudflare ni Vercel, ni realiza peticiones continuas mientras está en segundo plano. Las solicitudes de edición se reciben por el bot privado de Telegram y se ejecutan en GitHub Actions, sin guardar tokens en el navegador.
