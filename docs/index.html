¿Cómo funciona «Quitar de Listas»?

En iPhone, el botón abre una orden ya rellenada en GitHub web, en una nueva pestaña. Pulsa «Create issue» para confirmar. Solo una orden creada por el propietario puede modificar las noticias. Al volver al panel, toca Actualizar para comprobar el borrado. Si se abre la app GitHub sin los datos, abre el enlace en Safari.

Acerca de los datos y la conexión

Esta web se sirve desde GitHub Pages. Consulta solo archivos editoriales públicos de GitHub, con una copia estática de respaldo. No utiliza Cloudflare ni Vercel, ni realiza peticiones continuas mientras está en segundo plano. Las solicitudes de edición se confirman con tu cuenta GitHub y se ejecutan en GitHub Actions, sin guardar tokens en el navegador.
