1. Importa publicaciones que ya hayas consultado en X

En Chrome puedes abrir la búsqueda de tus publicaciones, desplazarte manualmente por el historial y usar Guardar página como… (HTML). Carga aquí ese archivo guardado. La web de X carga contenido de forma dinámica: un HTML guardado puede contener solo una parte del historial, y el contador te avisará de esa limitación.

No basta con pegar la URL de una búsqueda: necesitamos los enlaces o los datos de las publicaciones individuales. Se eliminan duplicados y los enlaces de otras cuentas no cuentan.
