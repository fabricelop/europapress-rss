# TTiTTulares manual-run trigger

Rama técnica destinada exclusivamente a mantener abierto el PR permanente que actuará como canal de disparo para ChatGPT Work.

- No fusionar en `main`.
- No usar para desarrollo.
- Los comentarios `RUN TTITTULARES` son solicitudes de ejecución manual.
- Los comentarios `RUNSTATUS <command_id>` son telemetría de Work.
